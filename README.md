# AI Cover Letter Generator

## Project Description

This project is a React application that generates professional cover letters using Google's Gemini AI.

## Features

- Candidate Name
- Job Role
- Target Company
- Key Skills
- Resume Upload (PDF)
- AI Generated Cover Letter
- Copy to Clipboard
- Loading State

## Technologies Used

- React
- Vite
- JavaScript
- Google Gemini API
- pdfjs-dist

## Installation

```bash
npm install
```

Run the project

```bash
npm run dev
```

Create a .env file

```
VITE_GEMINI_API_KEY=YOUR_API_KEY
```
